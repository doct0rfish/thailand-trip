# 태국 여행 사이트 · GitHub Pages

10월 15일 추천 일정 반영, 마사지 관련 내용 제거, 맛집 23곳 설명 포함.

## 업로드
1. 압축을 풉니다.
2. 압축 안의 파일들을 GitHub 저장소 루트에 업로드합니다.
   index.html이 저장소 최상위에 있어야 합니다.
3. Settings → Pages → Deploy from a branch를 선택합니다.
4. main / (root)를 선택하고 Save를 누릅니다.

주소: https://깃허브아이디.github.io/저장소이름/

별도 빌드나 패키지 설치는 필요하지 않습니다.
체크 상태는 브라우저별로 저장되며 사이트 주소가 달라지면 공유되지 않습니다.
