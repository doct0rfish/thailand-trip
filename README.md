# 태국 여행 수첩

2026년 9월 28일 기준 최신 여행 사이트입니다. 별도 설치나 빌드 없이 GitHub Pages에서 실행됩니다.

## 업로드

1. ZIP을 압축 해제합니다.
2. GitHub 저장소의 Pages 게시 폴더에 압축 해제한 파일을 모두 업로드합니다. ZIP 자체를 업로드하지 않습니다.
3. 기본 설정은 main 브랜치의 /(root)입니다. 이 경우 index.html이 저장소 최상위에 있어야 합니다.
4. 기존 사이트를 업데이트한다면 index.html만 교체하지 말고 JS, CSS, 이미지 파일도 함께 교체합니다.
5. 저장소 Settings → Pages에서 Deploy from a branch, main, /(root)를 선택하고 저장합니다. 기존 설정이 다른 브랜치나 /docs라면 해당 게시 위치에 파일을 넣습니다.
6. 배포가 완료되면 Pages 주소를 열고 새로고침합니다. 이전 내용이 보이면 Ctrl+Shift+R로 새로고침합니다.

방문 체크와 준비물 체크는 각 브라우저에만 저장됩니다.
